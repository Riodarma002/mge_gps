# Folder Company Logos

Tempatkan file logo perusahaan di folder ini dengan nama sesuai **prefix/initial** unit.

## Format Nama File
| Prefix Unit | Nama File |
|-------------|-----------|
| MGE         | MGE.png   |
| SMP         | SMP.png   |
| dll...      | PREFIX.png |

## Cara Kerja
- Unit `MGE-GHT-714` → akan mencari `/company/MGE.png`
- Unit `SMP-EX-42`   → akan mencari `/company/SMP.png`

## Ukuran Yang Disarankan
- **Format**: PNG dengan background transparan
- **Ukuran**: 64×64px atau 128×128px (akan di-resize ke 18×18px di peta)
- **Background**: Transparan agar terlihat baik di peta

## Label Design
```
[LOGO] [ GHT 714 ]   ← white chip, teks dark grey
          ▼
       [🚛 icon]
```
